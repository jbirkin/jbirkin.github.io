Code

Code I've written and released publicly. Most of it comes out of my research years and is aimed at astronomers, though the underlying problems — packaging something other people can install, keeping an analysis reproducible, designing an interface someone else can use without reading the source — are the same ones I work on now.

cubespecfit — fitting models to 3-D data cubes

A Python package for fitting an emission-line model independently at every pixel of a spectral data cube. It handles adaptive binning where the signal is weak, exposes a model interface so users can supply their own line profiles rather than editing the source, and emits diagnostic maps for checking where a fit has gone wrong. Written to be reused by collaborators, not just to make one paper's figures.

alma-stacking-pipeline — aggregating weak signals

A pipeline for aligning, normalizing and combining many low signal-to-noise spectra so that features invisible in any single one become measurable. Includes MCMC model fitting, dropout filtering, bootstrap error estimation and catalog utilities, and ships a setup.py so it installs and runs somewhere other than the machine it was written on.

Collaborative data review app

A Dash/Python web application for browsing multi-wavelength image cutouts from the SPT3G survey, deployed on AWS, so a distributed team could inspect and annotate candidates in one place.
